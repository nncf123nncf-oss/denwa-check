# 電話の聞き漏れチェック

電話で予約・注文・預かりを受けながら、聞いた順に項目を埋めていくWebページです。
100日100プロダクトチャレンジ Day096。

## できること

- 場面を3つから選ぶ（予約／注文・取り置き／預かり・修理）。場面ごとに聞く項目は6つ
- 埋めた項目にチェックが付く。日付を選ぶと曜日が付く（確認の文にも曜日入りで入る）
- 「電話を切る前に」を押すと、まだ聞いていない項目だけが赤く残り、入っている項目から読み上げる確認の文ができる
- 切ったあとに、控えメモ（複数行）とカレンダー用の題名（1行）をコピーできる

## 使わないもの・しないこと

- 登録・ログインはありません
- 入力した内容は保存しません（ページを閉じる・再読み込みすると消えます）。電話番号などをこの端末の外に送りません
- 通話の録音・文字起こし、予約の一覧管理、自動送信はありません

## 作り

HTML1枚（`index.html`）。外部ライブラリなし。アクセス解析に Cloudflare Web Analytics を使っています（フッタに明記）。
